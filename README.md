## Краткое описание содержимого
* api_tests - тесты для апи
* selenium_tests - тесты с использованием Selenium
* fixtures - подпапка для фикстур
* locators - подпапка для локаторов элементов

## Инструкции по запуску тестов
1. Убедитесь, что у вас установлена требуемая версия python (указана ниже),
а также необходимые библиотеки и зависимости (указаны в файле requirements.txt)
2. Запустите тест командой pytest

## Версия python
3.14.0
